# Dalhousie Recruitment Prototype

A conceptual undergraduate recruitment website for Dalhousie University inspired by the discovery mechanics of streaming platforms.

## Concept

Instead of forcing prospective students through a traditional alphabetical program catalogue, the prototype groups programs into browsable, visual collections such as:

- Trending with future students
- Big questions. Real-world work.
- Careers with momentum
- Not ready to choose just one thing?

The experience also includes search, interest filters, saved programs, comparison prompts, lightweight personalization, admissions and cost tools, advisor support concepts, campus visit prompts, and application conversion points.

## Running the prototype

Open `index.html` in a browser, or serve the repository as a static site.

## GitHub Pages

This repository is structured so the root `index.html` can be published directly with GitHub Pages from the `main` branch.

In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Status

This is a concept prototype, not an official Dalhousie University website. Program, admissions, tuition, and other institutional information should be validated against official Dalhousie sources before production use.
